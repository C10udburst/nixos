## 3. Co-location & Underscore Convention

Any file that is **not** a NixOS/dendritic module must be prefixed with an underscore `_` or placed in a directory prefixed with `_`.
This ensures that `inputs.import-tree ./modules` skips non-module files, preventing evaluation errors:

- Templates: `_config.toml.j2`, `_theme.reg.j2`, `_Konsole.profile.j2`
- Helper scripts: `_plot.py`, `_pd.py`, `_scope.sh`
- Media assets: `_wallpaper.jpg`, `_icon.png`
